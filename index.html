MKTVHub/TV

mkTV

Live

A web browser built for the TV remote

mkTV is a free, open-source web browser for Android TV and Google TV that you control with the remote's D-pad. It blocks ads and trackers, plays video full screen, and lets you type from your phone.

  • Ad and tracker blocking
  • D-pad jump navigation, tabs and per-site zoom
  • Phone remote by QR code, YouTube TV mode and private browsing
  • Android TV
  • Google TV

AgentSkillDeck/AI & agents

AgentSkillDeck Skills

Open source

Open plugins and skills for Claude Code and other coding agents

A plugin marketplace with two plugins, ui and audio, holding seven skills for coding agents. ui designs, reviews and matches interfaces, and audio turns a script into multi-voice audio on your own machine.

  • ui plugin: design, review, design-system research and screenshot-to-UI
  • audio plugin: scripts, on-device voices, captions and licensed sound
  • Install with /plugin marketplace add AgentSkillDeck/skills
  • Claude Code
  • Coding agents
WebsiteGitHub

AgentSkillDeck/Mac apps

Keepwatch

Live

Keep your Mac awake while AI agents run

Keepwatch is a free, open-source menu-bar app and command-line tool that keeps your Mac awake while Claude Code, Codex and other agents run, even with the lid closed. It goes back to sleep on schedule and shows live mic and camera status.

  • Lid-closed sessions that sleep on schedule
  • Live microphone and camera indicators
  • CLI for agents, also via brew install agentskilldeck/tap/keepwatch-cli
  • macOS
  • Linux (beta)
  • Windows (beta, CLI)
WebsiteGitHubDownload

JobCairn/AI & agents

JobCairn

Early access

A desktop job search app that works with your Claude plan

JobCairn is a Mac app, with a Windows beta, that finds jobs in your own Chrome, scores your fit, checks ads for visa sponsorship wording and tailors your resume and cover letter. It runs on your own Claude plan, keeps every file on your computer and asks for your approval at each step.

  • Fit score and interview odds, backed by lines from your resume
  • Visa sponsorship score from the ad and employer
  • Tailored resume and cover letter, 17 templates, PDF or Word
  • macOS
  • Windows (beta)
WebsiteGitHubDownload
OC

JKL404/AI & agents

Offline Chat Application

Open source

Private AI chat that runs local models through Ollama

A self-hosted chat app that talks to open-source models such as DeepSeek, Llama and Mistral through Ollama on your own machine. Conversations and processing stay on the device, with a FastAPI backend and a plain JavaScript frontend.

  • Switch between local models like DeepSeek, Llama and Mistral
  • Image upload for vision models such as LLaVA
  • Conversation history, system prompts and model parameter controls
  • macOS
  • Windows
  • Linux

JKL404/Games

Ludo Raja

Live

Real-time multiplayer Ludo for friends on the same WiFi

Ludo Raja is a browser-based multiplayer Ludo game you host on your own Mac and play from any device on the same WiFi. It runs without app installs or internet access, and a hosted version is also available online.

  • 2 to 4 players with optional AI bots in any seat
  • Room codes, reconnect, and live sync over Socket.IO
  • Classic and Galaxy board themes with chat and emoji reactions
  • Web
  • macOS
WebsiteGitHub
